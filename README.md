# CLAW-CT-Deeplearning-based-segmentation
CLAW_data Dataset
The folder named ''CLAW_data'' dataset contains CT images and their corresponding annotated label data for a total of 14 claws. 
The dataset is organized in a simple naming convention to make it easy to identify the CT image and its corresponding annotation. 
The CT images are named sequentially from c1 to c14, where each name represents one claw CT image. 
For example, c1 represents the CT image of claw 1, c2 represents claw 2, and this continues up to c14, representing claw 14.

For each CT image, a corresponding annotated dataset is provided using the same claw number followed by an underscore and the claw number. 
The annotation files are named c1_1, c2_2, c3_3, and so on through c14_14. Therefore, each CT image has a directly corresponding annotation; 
for example, c1 is associated with c1_1, c2 with c2_2, and c14 with c14_14. The complete dataset is stored in the main folder named CLAW_data. 
This consistent naming convention allows the CT images and their annotated labels to be easily matched and used for image analysis, segmentation, object detection, and other computer vision applications.
